common display / 共通表示
針は糸端に接続して進みます。千鳥かがりでは針先が折れ点の地割り線を糸幅の半分だけ越えた位置で止まり、針先を支点に針の終端を外側へ回して手毬に寝かせます。続いて針は地割り線を挟んだ対称位置へまっすぐ進みますが、刺入位置は元の表面位置に戻し、針先が水平方向に進んで内部を通過し始めた短い間だけ、周囲の手毬表面が小さく盛り上がるように表示します。針の終端が抜けると、その盛り上がりは元に戻ります。終端が抜けたあとにその終端を支点として次の目標点方向へ回転します。糸は前の折れ点から針の終端へ張られ、必要に応じて球面へ順に伏せ込まれます。上掛け／下掛けなど原典で上下関係が明記される工程では、現在糸の深さも上／下に変化させます。
点・番号について 白丸は現在動いている糸先です。数字・英字は、参照元の図で指定された点番号を優先して表示します。原典に点名がない工程では、動きを追いやすくするための補助番号を表示する場合があります。3D上の位置は原典の順序・隣接関係を保ちながら球面へ相対座標化しているため、絶対寸法を示すものではありません。

特徴と使い方

かがり手まりの制作を、①手まり芯、②地割り、③かがりの順で追える3D工程ビューアです。糸だけでなく針の向き・刺入・球内通過、かがりの上下関係も工程に合わせて表示します。

FEATURES / 特徴

  • 複数の代表図案を工程順に再生し、1手・1フレーム単位でも確認できます。
  • 通常の球体、平面展開、正20面体、切頂20面体、正12面体に加え、北・南半球を並べた正射図法で確認できます。
  • 糸色・太さ・線種を共通または糸ごとに設定でき、リアリスティック3D素材も選択できます。
  • 手まり直径から地割り糸とかがり糸の幾何学的な経路長を推定します。
  • 平面系の表示モードはSVGとして出力できます。
  • 各図案には参照した手まり技法・図案サイトへのリンクがあります。

CONTROLS / 基本操作

  • 再生／停止：上部の線画アイコン。スマートフォンでは3D表示部分のタップでも切り替えます。
  • 1手進む・戻る：工程単位で移動します。1フレーム進む・戻る：針の動きを細かく確認します。
  • PC：ドラッグで回転、Shift＋ドラッグで平行移動、ホイールで拡大縮小します。
  • スマートフォン：1本指で操作し、2本指ピンチで拡大縮小します。
  • 画面下のタイムラインは任意位置へ移動できます。
  • 設定は右上の settings から表示／非表示を切り替えます。

ORTHOGRAPHIC / 正射図法

「正射図法（北半球・南半球）」では、球を北極側と南極側から正射投影した2つの円を横に並べます。同じ経度方向をそろえているため、極を中心とする図案や地割りの対応を比較しやすくしています。

本アプリは教育・工程理解を目的とした可視化です。図案ごとの公開資料に工程や寸法が明記されている場合はそれを優先し、球面上の寸法は表示用に正規化している場合があります。
